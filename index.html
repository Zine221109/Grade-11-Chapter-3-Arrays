Unit 3.1 – Introduction to Arrays

An array is a data structure that stores multiple values of the same type linked to a single variable name. Think of it like a row of labelled boxes — each box holds one value and has an index number.

🤔 Why Do We Need Arrays?

Imagine storing 100 test scores. Without arrays you'd need:

iScore1, iScore2, iScore3, ... iScore100: Integer; // 😩 100 separate variables — impossible to loop through!

With an array, you only need one declaration and a loop:

arrScores: array[1..100] of Integer; for i := 1 to 100 do arrScores[i] := StrToInt(InputBox('Score','Enter score','')); // ✅ Clean, efficient, loopable!
🏗️ Array Declaration Syntax
var arrayName: array[StartIndex..LastIndex] of DataType;
ComponentMeaningExample
arrayNameName with arr prefixarrNames, arrScores
StartIndexFirst index position1

Real examples from your coursework:

arrNames: array[1..20] of String; arrAges: array[1..120] of Integer; arrAlphabet: array[1..26] of Char; arrProvinces: array[1..9] of String; // Constant array (elements cannot change): const arrDays: array[1..7] of String = ('Sun','Mon','Tue','Wed','Thur','Fri','Sat');

📥 Populating an Array
Method 1

Assign fixed values directly:

arrSchools[1] := 'New Forest'; arrSchools[2] := 'Stanger High'; arrSchools[3] := 'Mountview High';
Method 2

Use InputBox + FOR-loop:

for i := 1 to 5 do arrScores[i] := StrToInt( InputBox('Score', 'Enter score',''));
📤 Displaying Array Elements
❌ Inefficient
memDisplay.Lines.Add(IntToStr(arrScore[1])); memDisplay.Lines.Add(IntToStr(arrScore[2])); memDisplay.Lines.Add(IntToStr(arrScore[3])); // Imagine doing this for 100 items!
✅ Efficient
for i := 1 to 5 do memDisplay.Lines.Add( IntToStr(arrScores[i])); // Loop through all elements!
➕➖ Inserting & Deleting Elements

When inserting at position 4, shift elements right first (starting from the last element). When deleting from position 3, shift elements left.

INSERT at position 4
// Shift right (last element first) for i := 10 downto 4 do arr[i+1] := arr[i]; // Then insert the new value arr[4] := newValue;
DELETE from position 3
// Shift left (4th position first) for i := 3 to 9 do arr[i] := arr[i+1]; // Display only first 9 elements
Never start shifting from the insert position — you'll overwrite existing values!
Unit 3.2 – Searching & Sorting Arrays

When working with large data, you need to find and organise elements efficiently. This unit covers two search methods and two sort algorithms.

🔍 Linear Search

The linear search loops through each element from the beginning until the target is found or the end is reached. Best for unsorted or small arrays.

i := 1; iPos := 0; bFlag := false; sSearch := InputBox('Search', 'Enter name', ''); while (i <= 10) and (bFlag = false) do begin if arrNames[i] = sSearch then begin bFlag := true; iPos := i; end; inc(i); end; if bFlag = true then memDisplay.Lines.Add('Found at position: ' + IntToStr(iPos)) else memDisplay.Lines.Add(sSearch + ' not found');
Use a Boolean flag (bFlag) and a position variable (iPos) to track search results. The loop exits as soon as the item is found!
🎯 Binary Search

Binary search is much faster for sorted arrays. It repeatedly halves the search range until the target is found. For 10 000 elements, linear search may need 10 000 checks — binary search needs at most 14!

How it works: Find the midpoint. If the target equals mid, done! If the target is greater than mid, search the RIGHT half. If less, search the LEFT half. Repeat until found or range is empty.
// Array must be SORTED first! lowerBound := 1; upperBound := Length(arrNumbers); bFound := false; while (bFound = false) and (lowerBound <= upperBound) do begin mid := (lowerBound + upperBound) div 2; if searchValue = arrNumbers[mid] then bFound := true else if searchValue > arrNumbers[mid] then lowerBound := mid + 1 // Search RIGHT half else upperBound := mid - 1; // Search LEFT half end;
🫧 Bubble Sort

Bubble sort compares adjacent elements and swaps them if they are in the wrong order. The smallest (or largest) element "bubbles" to its final position after each pass.

// Bubble Sort – Descending Order for i := Length(arr)-1 downto 1 do for j := 1 to i do if arr[j] < arr[j+1] then // swap if smaller comes before larger begin iTemp := arr[j]; arr[j] := arr[j+1]; arr[j+1] := iTemp; end; // Bubble Sort with Flag (more efficient – stops early if sorted!) repeat bFlag := true; // assume sorted for j := 1 to 9 do if arr[j] > arr[j+1] then // swap begin iTemp := arr[j]; arr[j] := arr[j+1]; arr[j+1] := iTemp; bFlag := false; // swapping occurred – not yet sorted end; until bFlag = true;
🎯 Selection Sort

Selection sort selects the element that should go in each position and places it there. It compares element at position 1 with every other element, swapping when needed.

// Selection Sort – Ascending Order for i := 1 to 4 do for j := i+1 to 5 do if arr[i] > arr[j] then // if out of order, swap begin iTemp := arr[i]; arr[i] := arr[j]; arr[j] := iTemp; end;
Tip: You only need to apply ONE sorting algorithm in your practical assessments. Choose bubble sort with flag as it's the most efficient of the two!

Unit 3.3 – Parallel Arrays

Parallel arrays store related information of different data types in separate arrays, linked by their index position. If arrNames[3] = 'Peter', then arrMarks[3] = Peter's mark.

🔗 What Are Parallel Arrays?

You cannot mix data types in one array. Use two (or more) arrays where index positions correspond:

arrNames (String):
arrMarks (Integer):
arrNames[3] = 'Peter' and arrMarks[3] = 91 — they are linked by position 3! Click a cell above to see the link.
🔎 Searching Parallel Arrays

Search one array, use the found index to get data from the other:

sSearch := InputBox('Name', 'Enter name', ''); i := 1; iPos := 0; bFlag := false; while (i <= 10) and (bFlag = false) do begin if arrNames[i] = sSearch then begin bFlag := true; iPos := i; end; inc(i); end; if bFlag = true then memDisplay.Lines.Add('Mark: ' + IntToStr(arrMarks[iPos])) // Use the SAME iPos to access the parallel array!
🔃 Sorting Parallel Arrays

When sorting, you must swap both arrays simultaneously, otherwise the data gets mislinked!

for i := 1 to 4 do for j := i+1 to 5 do if arrMarks[i] < arrMarks[j] then // sort marks descending begin // Swap marks iTemp := arrMarks[i]; arrMarks[i] := arrMarks[j]; arrMarks[j] := iTemp; // Swap names too! (keep them linked) sTemp := arrNames[i]; arrNames[i] := arrNames[j]; arrNames[j] := sTemp; end;
If you only sort one array and forget the parallel array, the names and marks will become mismatched! Always swap both.
🎬 Real World Example – Box Office

From your practical book: A cinema stores movies and ticket sales in parallel arrays. This is a typical exam scenario!

// Two parallel arrays declared globally: const arrMovies: array[1..5] of String = ('Dune','Avatar','Barbie','Oppenheimer','Elemental'); arrTickets: array[1..5] of Integer = (340, 521, 489, 412, 198); // Block Adjust: Add 100 sponsored tickets to ALL movies for i := 1 to 5 do arrTickets[i] := arrTickets[i] + 100;
